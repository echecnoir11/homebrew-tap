# echecnoir11/homebrew-tap

Homebrew tap for [@@ennuienoir](https://github.com/echecnoir11/ennuienoir) — experimental video effects for macOS.

```bash
brew tap echecnoir11/tap
brew install --cask ennuienoir
brew upgrade --cask ennuienoir      # update
brew uninstall --cask ennuienoir    # remove (add --zap to also delete presets and caches)
```

If Homebrew reports an *untrusted tap*, run `brew trust echecnoir11/tap` once.

The app is not notarized: on first launch open System Settings › Privacy & Security and click **Open Anyway**.
